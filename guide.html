01 / Run locally

Since the browser loads JSON with fetch(), open the site through an HTTP server rather than double-clicking the HTML file.

python3 -m http.server 8000 --bind 127.0.0.1

Then open http://127.0.0.1:8000/ in your browser.

02 / Edit profile data

Open data/profile.json and replace the name, introduction, skills, experience, and education. Changes appear on the home and resume pages after reloading.

Delete any sample entries you cannot verify. The example identity and project descriptions are fictional.

03 / Add a project

Edit data/projects.json. Add a new object with a unique id and slug, title, summary, content, stack, and metadata. The listing and project-detail page are generated automatically.

Use a slug like my-first-project. Set featured to true to display a project on the homepage. Optional source and demo links must be HTTPS URLs.

04 / Replace the sample PDF

Replace assets/sample-resume.pdf with a verified resume, or update the relative PDF path in data/profile.json. The sample PDF deliberately contains placeholders.

05 / Publish with HTTPS

This folder is deploy-ready but is not itself a hosted website. Follow docs/deployment.md for GitHub Pages, a custom domain, DNS, HTTPS, and deployment checks.

GitHub Pages can provide HTTPS for its own domain. A custom domain requires a domain you control and DNS configuration.

Before publishing, search the project for Your Name, example.com, 20XX, and demo, and replace every relevant placeholder.
