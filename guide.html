Site guide.

このサイトで紹介する成果物の範囲と、コード・評価結果へのアクセス方法をまとめています。

目次

サイトの構成成果物と根拠作品の追加方法ローカル実行公開情報の扱い

01 / サイトの構成

静的HTML・CSS・JavaScript（ES modules）で構成しています。作品一覧はdata/projects.jsonを読み込み、検索・カテゴリ別の表示と共通の詳細ページを提供します。Aboutはdata/profile.jsonの技術情報を表示します。

02 / 成果物と根拠

Machine Learning Algorithmsでは、公開コードで再現できるε-greedy法の数値実験と、講義発表時の分析を区別しています。実験CSV、理論ノート、検証資料へのリンクを詳細ページに掲載しています。

ChatBotでは、画面・API・DB・外部AI連携の構成を説明しています。ローカルでの検証と実API通信、公開運用の実績は区別しています。

03 / 作品を追加する

data/projects.jsonに一意のid・slug、タイトル、要約、課題、方法、結果と制約、技術スタック、GitHubソースURLを追加します。詳細な処理手順にはworkflow、検証対象の指標にはhighlights、裏付け資料にはresourcesを指定できます。

正確なデータ構造は編集ガイドを参照してください。完成・検証済みの範囲だけを記載します。

04 / ローカルで確認する

プロジェクトデータはfetch()で取得するため、HTMLを直接開くのではなくHTTPサーバー経由で確認してください。

python3 -m http.server 8000 --bind 127.0.0.1

http://127.0.0.1:8000/を開き、テストはbash scripts/verify.shで実行できます。

05 / 公開情報の扱い

GitHub上で公開済みのコードと検証結果を中心に記載し、氏名・連絡先・未確認の学歴や職歴は掲載していません。数値実験の結果は特定条件の観察であり、一般的な最適性や統計的な有意差を意味するものではありません。
